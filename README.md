# portfolio-scripts

Code and web-ready images for Timothy Owen's portfolio site (built in Webflow).
Webflow pages load these files through jsDelivr, a free service that serves files from public GitHub repositories.

## What's here

| Folder | What it holds |
|---|---|
| `css/site.css` | The shared styles: the desk, the type, every case-study layout. Loaded on every page. |
| `js/` | One script per page. `posters.js` runs the Hockey Posters desk and its print viewer. |
| `img/` | Web-ready images, one folder per page. |
| `snippets/` | The page markup that goes into Webflow, kept here as a reference copy. |

## Updating a file

Open the file on GitHub, click the pencil icon (or upload a replacement with **Add file → Upload files**), then **Commit changes**.
Changes can take a little while to reach the live site, because jsDelivr caches files; new versions are published as releases (v1.0.0, v1.0.1, …) so each change is picked up straight away.
